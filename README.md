# Yins 隐私助手

把不想让别人看到的 App 和文件**加密隐藏**起来。平时打开只是一个普通的记事本，只有你按下快捷键、验证指纹或密码后才能进入隐私设置。

## 一、安装

1. 打开下载好的 **Yins.dmg**，把 Yins 图标拖进「应用程序」文件夹。
2. 第一次打开：在「应用程序」里**右键点 Yins → 打开**，再点一次「打开」。
   - 如果提示「无法验证开发者」或「已损坏」：打开 **系统设置 › 隐私与安全性**，往下找到 Yins，点「**仍要打开**」。
   - 还是打不开：打开「终端」，粘贴下面这行并回车，然后再双击 Yins：
     ```
     xattr -dr com.apple.quarantine /Applications/Yins.app
     ```
3. 打开后看到的是**记事本和今日屏幕使用时间**，这是 Yins 的伪装界面，别人看到也只会以为是个记事本。

## 二、第一次设置（约 2 分钟）

1. **进入隐私设置**：在任何地方按 **⌃ Control + ⌥ Option + ⌘ Command + Y**（可以在设置里改），或者长按记事本右下角 2 秒。
2. **开启加密保护**：设置一个密码（推荐字母加数字），可以顺便打开 Touch ID。屏幕上会给你一个**恢复码，请抄下来保存好**，忘了密码时只能靠它。
3. **开启权限**：接着会弹出权限引导，每项点一下就好：
   - **完全磁盘访问权限（必需）**：点「开启」会打开系统设置，并在屏幕右下角浮出 Yins 图标，把它拖进列表，再打开开关。没有它，微信、QQ、Telegram 这类 App 的聊天记录没法一起加密。
   - 通知、辅助功能、录屏：点「开启」后在系统弹框里点「允许」即可（辅助功能、录屏只有隐藏打开着的文件、截图时才用得到）。
   - 系统规定这些开关只能由你本人打开，任何 App 都不能替你打开；开过一次，以后更新也不用再开。

## 三、怎么用

| 想做的事 | 怎么做 |
|---|---|
| 隐藏 App | 隐私设置 › **隐藏 App** › 新建分组，把微信、QQ 等加进去，点分组上的开关 |
| 隐藏文件 / 文件夹 | 隐私设置 › **隐藏文件**，直接把文件拖进去 |
| 自动隐藏 / 恢复 | 隐私设置 › **自动规则**：按时间段、按地点、按每天使用时长 |
| 恢复 | 再点一次开关，用 Touch ID 或密码验证，全部放回原处，打开后跟以前一样 |
| 回到记事本 | 再按一次快捷键，或点左下角「回到记事本」；离开 Yins 一会儿也会自动回去 |
| 截图 | 按 **⌃ Control + ⌥ Option + A**，鼠标停在哪就框出哪，可以标注、识别文字 |

**隐藏 App 时做了什么**：先把 App 完全退出，再把 App 本体和它的数据（聊天记录、浏览记录、登录信息等）加密成随机名字的文件，原来的删除。程序坞、启动台、聚焦搜索里都不会再出现。

## 四、常见问题

**别人用技术手段能找到吗？**
找不到，也打不开。隐藏的内容用你的密钥加密，文件名是随机的，连 App 名、文件名都看不到。把硬盘拷走也解不开。注意：恢复出来正在用的时候，和普通 App 一样能被看到。

**忘了密码怎么办？**
在解锁框点「忘记密码？」，输入恢复码，进去后设新密码。密码、指纹、恢复码都没有的话，就没有任何办法打开。

**聚焦搜索还能搜到？**
确认已经打开「完全磁盘访问权限」，然后进一次隐私设置，Yins 会自动把漏掉的数据补上加密。如果 iPhone 上也装了这个 App，搜索结果里可能出现「iPhone 上的 App」，那不是这台 Mac 上的。

**隐藏时提示「系统阻止」？**
到 系统设置 › 隐私与安全性 › **App 管理**，打开 Yins。

**东西找不回来了？**
隐私设置 › 设置 › 存储与恢复 › **紧急恢复**，会把所有隐藏的内容解密放回原处。

## 五、更新

Yins 会自动检查新版本，有更新时在隐私设置左下角提示，点「立即更新」就好。也可以在 设置 › 更新 里手动检查。更新包都有发布者签名，核对通过才会安装。**已激活的 Pro 更新后保持不变，不用重新激活。**

## 六、隐私

所有数据只保存在你自己的 Mac 上，不上传任何内容。Yins 只在检查和下载新版本时访问 GitHub。
